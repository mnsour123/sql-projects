Online Shopping Database

A simple SQL project that simulates an online shopping system. It demonstrates relational database design and basic SQL operations.

Features

- Customer Management
- Product Management
- Category Management
- Order & Payment Management
- Sales Reports

Database Tables

- Customers
- Categories
- Products
- Orders
- Order_Details
- Payments

SQL Concepts Used

- CREATE TABLE
- INSERT
- SELECT
- JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions
- Primary & Foreign Keys

#How to Run

1. Create the database.
2. Run the table creation scripts.
3. Insert the sample data.
4. Execute the SQL queries to view reports.

Purpose

This project was built to practice SQL database design, relationships, and querying using a real-world e-commerce example.
